# Простая LLM-модель для предсказания следующего слова (Вариант 1)

Домашнее задание: реализация статистической N-граммной (биграммной) языковой модели на Python 3, которая обучается на подготовленном датасете и предсказывает следующее слово на основе частоты встречаемости пар слов.

## Описание решения

В классе `TestLLM` реализован метод `train(data)`, который:
1. Приводит каждое предложение из обучающей выборки к нижнему регистру и разбивает его на отдельные слова (токены).
2. Проходит по всем соседним парам слов `(текущее_слово, следующее_слово)`.
3. Подсчитывает частоту появления каждого следующего слова в словаре `self.ngram_counts`.

Метод `predict_next_word(start_word)` выбирает и возвращает слово с максимальной частотой появления после заданного входного слова.

## Требования

* Python 3.10 и выше (сторонние библиотеки не требуются, используется стандартный модуль `collections`).

## Запуск проекта

Выполните команду в терминале из корневой папки проекта:

```bash
python main.py
```
